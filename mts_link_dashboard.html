Архитектура МТС Линка

Базовая схема: одна постоянная встреча на уникальную учебную аудиторию + предмет. Поэтому 10А и 9Б у одного преподавателя получают разные постоянные ссылки и не видят материалы друг друга. Если несколько классов реально слушают одну общую лекцию одновременно, они считаются одной объединённой аудиторией и могут иметь одну постоянную встречу.

МТС Линк · постоянные встречи

Разделение материалов между классами

Единица постоянной встречи здесь — учебная аудитория + предмет. Один преподаватель может иметь несколько постоянных встреч: например, «10А · История» и «9Б · История». Записи и файлы разных аудиторий не смешиваются.

Важно: «постоянная встреча» — это одна неизменная ссылка для конкретной учебной аудитории. Каждый новый урок в ней даёт отдельную сессию/запись, но сама ссылка сохраняется на весь учебный год.

Оперативная координация

Готовность online-преподавателей

Отдельный групповой чат — только для преподавателей, которые ведут online, плюс администратор/резервный администратор. Здесь не методические обсуждения, а быстрый чек готовности и решение технических инцидентов.

Личный рабочий контур

Отсечки после онлайн-дней

После последнего online-урока дня закрываем весь хвост в один заход: запись МТС Линка → ИИ-транскрипция → полноценный конспект → нужный курс EDU.FA.RU. Прогресс хранится в этом браузере отдельно для каждой недели.

Правило записи: преподаватель завершает сессию МТС Линка после каждого 45‑минутного урока. Тогда одна запись = один урок = один будущий конспект. Постоянная ссылка этой учебной встречи остаётся прежней.

EDU.FA.RU · подготовка один раз

Сколько курсов создать и кого куда зачислять

Рекомендованная схема: один курс на параллель + предмет. Внутри курса создаются группы Moodle по классам/подгруппам, а конкретный конспект ограничивается нужной группе. Это резко уменьшает число курсов и при этом не смешивает материалы для детей.

Расписание содержит классы и подгруппы, но не содержит ФИО учеников. Поэтому ниже точно показано, какую группу детей надо добавить в курс; сами ФИО/логины берутся из выгрузки ЭлЖура или вашего файла учётных записей EDU.FA.RU.
