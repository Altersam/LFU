Магнитный поток Φ

Определение

Магнитный поток — скалярная величина, равная произведению модуля вектора магнитной индукции на площадь контура и косинус угла между вектором B и нормалью к контуру.

Φ = B · S · cos α Φ — магнитный поток, Вб  |  B — индукция, Тл  |  S — площадь, м²

Когда Φ = 0?

  • B = 0 (нет магнитного поля)
  • S = 0 (нет контура)
  • α = 90° (плоскость контура параллельна силовым линиям)

Визуализация магнитного потока

Явление электромагнитной индукции

Суть явления

При изменении магнитного потока через замкнутый проводящий контур в нём возникает ЭДС, а значит — индукционный ток.

Важно: ЭДС возникает не от наличия поля, а от его изменения!

Способы изменения Φ

  • Изменение B — усиление/ослабление поля
  • Изменение S — изменение площади контура
  • Изменение α — поворот контура в поле
  • Движение — относительное перемещение контура и магнита

Демонстрация: магнит и катушка

Движение магнита → изменение Φ → ЭДС → отклонение стрелки

Закон Фарадея

Формулировка

ЭДС индукции в замкнутом контуре равна модулю скорости изменения магнитного потока через поверхность, ограниченную контуром.

ϵ = −N · ΔΦ / Δt ϵ — ЭДС индукции, В  |  N — число витков  |  ΔΦ/Δt — скорость изменения потока

Вывод формулы пошагово

Шаг 1. Магнитный поток: Φ = B · S · cos α
Шаг 2. Изменение потока за Δt: ΔΦ = Φ₂ − Φ₁
Шаг 3. Средняя ЭДС: ϵ = N · |ΔΦ| / Δt
Шаг 4. Знак «−» — правило Ленца (направление тока противодействует изменению Φ)

Когда меняется Φ?

ПараметрКак меняетсяПример
BУсиление/ослабление поляПоднесение магнита
SИзменение площади контураРастяжение проводника
αПоворот контураВращение катушки
ДвижениеОтносительное перемещениеВтягивание контура в поле

Правило Ленца

Формулировка

Индукционный ток направлен так, чтобы своим магнитным полем противодействовать изменению магнитного потока, вызвавшему этот ток.

Алгоритм определения направления

  • 1. Определите направление вектора B внешнего поля
  • 2. Определите: увеличивается или уменьшается Φ
  • 3. Если Φ ↑ — поле тока направлено против внешнего
  • 4. Если Φ ↓ — поле тока направлено вдоль внешнего
  • 5. По правилу правой руки определите направление тока

Практическое применение ЭМИ

⚙️ Электрогенератор

Вращение катушки в магнитном поле → непрерывное изменение Φ → переменная ЭДС → электрический ток

🔌 Трансформатор

Переменный ток в одной катушке → Φ меняется → ЭДС во второй катушке. Повышение/понижение напряжения.

Задачи — базовый уровень

Задача 1

В катушке с числом витков N = 200 магнитный поток изменяется от Φ₁ = 0,02 Вб до Φ₂ = 0,08 Вб за время Δt = 0,1 с. Найти среднее значение ЭДС индукции.

Дано: N = 200, Φ₁ = 0,02 Вб, Φ₂ = 0,08 Вб, Δt = 0,1 с

Формула: ϵ = N · (Φ₂ − Φ₁) / Δt

ϵ = 200 · (0,08 − 0,02) / 0,1 = 200 · 0,6 = 120 В

Ответ: 120 В

Задача 2

Круглый контур площадью S = 0,05 м² находится в однородном магнитном поле B = 0,4 Тл, перпендикулярном плоскости контура. Магнитное поле уменьшается со скоростью 0,1 Тл/с. Определите ЭДС индукции и направление тока.

Дано: S = 0,05 м², dB/dt = 0,1 Тл/с, α = 0°

Формула: ϵ = S · |dB/dt|

ϵ = 0,05 · 0,1 = 0,005 В = 5 мВ

Направление: Φ убывает → индукционный ток создаёт поле вдоль внешнего → по часовой стрелке (при взгляде вдоль B).

Ответ: 5 мВ, по часовой стрелке

Задача 3

Квадратный контур со стороной a = 20 см вращается с частотой n = 50 об/с в однородном магнитном поле B = 0,2 Тл вокруг оси, перпендикулярной полю. Определите максимальное значение ЭДС индукции.

Дано: a = 0,2 м → S = 0,04 м², n = 50 об/с, B = 0,2 Тл

Формулы:

Φ(t) = B · S · cos(ωt),   ω = 2πn
ϵₙₕ = B · S · 2πn

Вычисление:

ϵₙₕ = 0,2 · 0,04 · 2 · 3,14 · 50 = 2,51 В

Ответ: ≈ 2,5 В

Задача 4

Катушка с индуктивностью L = 0,5 Гн и сопротивлением R = 10 Ом подключена к источнику ЭДС ϵ = 10 В. После замыкания цепи через время t = 0,05 с отключите источник. Какое максимальное напряжение возникнет на катушке?

1) Максимальный ток: I₀ = ϵ/R = 10/10 = 1 А

2) Постоянная времени: τ = L/R = 0,5/10 = 0,05 с

3) К моменту t = 0,05 с (= τ) ток: I = I₀(1 − e−1) ≈ 0,63 А

4) При размыкании Umax ≈ I · R = 0,63 · 10

Umax ≈ 6,3 В

Ответ: ≈ 6,3 В

ЕГЭ · Задание 23 Повышенный

Задача 5

Прямоугольный контур площадью S = 100 см² сопротивлением R = 2 Ом втягивается в однородное магнитное поле B = 0,5 Тл со скоростью v = 2 м/с. Активная сторона контура l = 10 см. Определите силу тока и силу Ампера.

Дано: B = 0,5 Тл, l = 0,1 м, v = 2 м/с, R = 2 Ом

1) ЭДС: ϵ = B · l · v = 0,5 · 0,1 · 2 = 0,1 В

2) Ток: I = ϵ/R = 0,1/2 = 0,05 А = 50 мА

3) Сила Ампера: F = B · I · l = 0,5 · 0,05 · 0,1 = 0,0025 Н

I = 50 мА,   F = 2,5 мН

Ответ: I = 50 мА, F = 2,5 мН
