Электромагнитная индукция

Как изменение магнитного потока создаёт ЭДС — и почему направление тока подчиняется закону сохранения энергии.

Φ = BS cos αℰ = −N·dΦ/dtправило Ленцазадачи ЕГЭ

Начать без определения. Спросить: «Будет ли ток в катушке, если рядом просто лежит магнит?» Затем: «Что должно изменяться?» Цель — сразу вывести класс на идею изменения магнитного потока.

Проблемная постановка ≈ 2 мин

Магнитное поле есть. Почему тока может не быть?

Ситуация A

Постоянный магнит неподвижен внутри катушки.

B ≠ 0, но Φ = const

Индукционного тока нет.

Ситуация B

Тот же магнит движется относительно катушки.

B меняется во времени → Φ меняется

Возникает ЭДС индукции.

Ключевая идея урока: электромагнитная индукция связана не с самим магнитным полем, а с изменением магнитного потока через контур.

Попросить учеников предсказать, будет ли отклоняться стрелка при остановке магнита. Подчеркнуть: B может быть большим, но если поток через контур постоянен, ЭДС индукции равна нулю.

Наблюдение → закономерность ≈ 3 мин

Что показывает опыт Фарадея?

1. Магнит неподвижен

Стрелка гальванометра возвращается к нулю.

Поток перестал меняться.

2. Движем быстрее

Отклонение стрелки становится больше.

Больше скорость изменения потока.

3. Меняем направление

Стрелка отклоняется в противоположную сторону.

Меняется знак dΦ/dt.

|ℰ| ∝ скорости изменения магнитного потока

Это не лабораторная работа: на уроке достаточно демонстрации или интерактивной визуализации.

Формулировать осторожно: опыт показывает зависимость ЭДС от скорости изменения потока. Закон Фарадея является количественным обобщением экспериментов.

Новый термин ≈ 4 мин

Магнитный поток Φ

Φ

Физический смысл

Характеризует, насколько сильно магнитное поле «пронизывает» выбранную поверхность.

Φ = B S cos α

для однородного поля и плоской поверхности

Что такое α?

α — угол между вектором B и нормалью n к поверхности.

Частая ошибка: считать α углом между B и самой плоскостью рамки. Покажите нормаль. Для B перпендикулярного плоскости α=0°, поток максимален; для B вдоль плоскости α=90°, поток ноль.

Три физических механизма ≈ 2 мин

Индукция возможна даже без движения магнита

B меняется

Меняется величина магнитного поля.

Например, ток в электромагните изменяется.

S меняется

Меняется площадь контура, находящаяся в поле.

Например, рамка входит в область поля.

α меняется

Рамка поворачивается относительно поля.

Основа работы генератора переменного тока.

Φ(t) = B(t) · S(t) · cos α(t)

Важно не что меняется, а то, что меняется магнитный поток.

Количественный закон ≈ 4 мин

От наблюдения к закону Фарадея

1

Эксперимент: чем быстрее меняется Φ, тем больше |ℰ|.

2

Средняя скорость изменения потока: ΔΦ/Δt.

3

В пределе Δt → 0 получаем производную dΦ/dt.

4

Знак «−» задаёт правило Ленца.

ℰср = − N · ΔΦ / Δt
ℰ = − N · dΦ/dt

N — число витков; Φ — поток через один виток.

Это не «вывод из другой формулы», а математическая запись экспериментального закона. Сильному классу подчеркнуть: производная означает мгновенную скорость изменения потока.

Проверка формулы ≈ 2 мин

Почему Вб/с — это вольт?

[ℰ] = [Φ]/[t] = Вб/с

По определению СИ:

1 Вб/с = 1 В

Смысл

Если поток через один виток изменился на 1 Вб за 1 с, модуль средней ЭДС в одном витке равен 1 В.

ЭДС зависит от темпа изменения потока, а не от его абсолютного значения.

Направление индукционного тока ≈ 4 мин

Знак «−» — это правило Ленца

Индукционный ток создаёт магнитное поле, которое противодействует изменению магнитного потока, вызвавшему этот ток.

Противодействует именно изменению, а не «всегда внешнему полю».

Связать с законом сохранения энергии: если бы возникающий ток усиливал движение магнита, система сама разгоняла бы магнит и одновременно производила электрическую энергию.

Алгоритм для задач ≈ 3 мин

Как определить направление тока за 4 шага

1

Определите направление внешнего B через контур.

2

Решите: магнитный поток увеличивается или уменьшается?

3

По Ленцу выберите направление собственного поля Bинд, которое мешает этому изменению.

4

По правилу правой руки найдите направление индукционного тока.

Не начинайте сразу с направления тока. Сначала поток → затем Bинд → только потом ток.

Связь с генератором ≈ 3 мин

Вращающаяся рамка → синусоидальная ЭДС

Пусть рамка вращается с постоянной угловой скоростью ω:

α = ωt
Φ = B S cos(ωt)

Тогда по закону Фарадея:

ℰ = −N dΦ/dt = NBSω sin(ωt)

Эта модель — мост к теме переменного тока.

Если времени мало, этот слайд можно пропустить. Для сильного класса это хороший «вывод формулы» на базе правила производной.

Типовая расчётная задача ≈ 3 мин

Изменяется магнитный поток

Условие. Магнитный поток через один виток катушки изменился от 8 мВб до 2 мВб за 0,020 с. Катушка содержит 50 витков. Найдите модуль средней ЭДС индукции.

Φ₁ = 8·10⁻³ Вб
Φ₂ = 2·10⁻³ Вб
Δt = 2,0·10⁻² с
N = 50

1. Изменение потока:

|ΔΦ| = |2−8|·10⁻³ = 6·10⁻³ Вб

2. Закон Фарадея:

|ℰ| = N·|ΔΦ|/Δt
|ℰ| = 50·6·10⁻³ / 0,020 = 15 В
Типовая задача на Φ ≈ 3 мин

Поле меняется, рамка неподвижна

Катушка из 200 витков имеет площадь каждого витка 50 см². Вектор B перпендикулярен плоскости витка. Индукция равномерно увеличивается от 0,20 Тл до 0,80 Тл за 0,050 с. Найдите модуль ЭДС.

Перевод площади: 50 см² = 5,0·10⁻³ м².

α=0°, поэтому cosα=1.

|ΔΦ| = S·|ΔB| = 5·10⁻³·0,60 = 3·10⁻³ Вб
|ℰ| = 200·3·10⁻³ / 0,050 = 12 В

Типичная ошибка: забыть перевести см² в м².

Авторская задача в формате ЕГЭ ≈ 3 мин

График Φ(t): где ЭДС максимальна?

Вопрос. На каком интервале времени модуль ЭДС индукции в одном витке наибольший?

Идея: |ℰ| = |dΦ/dt| — это модуль наклона графика Φ(t).

Авторская задача в формате ЕГЭ ≈ 2 мин

Может ли ЭДС быть нулевой при Φ ≠ 0?

Замкнутая рамка неподвижна в однородном постоянном магнитном поле. Магнитный поток через рамку равен 0,030 Вб и не меняется. Чему равна ЭДС индукции?

Это одна из главных концептуальных ловушек: Φ ≠ 0 не означает ℰ ≠ 0. Нужна величина dΦ/dt.

Антиошибки ≈ 2 мин

Пять ловушек, которые встречаются в задачах

❌ α — угол с плоскостью рамки.

✓ α — угол с нормалью.

❌ Есть B → обязательно есть ЭДС.

✓ Нужен dΦ/dt ≠ 0.

❌ Для катушки забываем N.

✓ ℰ = −N dΦ/dt.

❌ см² переводим как 10⁻² м².

✓ 1 см² = 10⁻⁴ м².

❌ Ленц «всегда против B».

✓ Он против изменения потока.

❌ Знак «−» используют как «ЭДС отрицательна».

✓ Знак фиксирует направление в выбранной ориентации контура.

ЭДС в движущемся проводнике

Прямой проводник длины l движется со скоростью v в однородном поле B.

|ℰ| = B l v sinβ

β — угол между B и v; в стандартной конфигурации β=90°.

Задача. l=0,40 м, B=0,50 Тл, v=6,0 м/с, B ⟂ v. Найдите ЭДС.

ℰ = 0,50·0,40·6,0 = 1,2 В
