# LFU — страницы Лицея Финансового университета

Сводный репозиторий HTML-страниц для Лицея Финансового университета при Правительстве РФ: расписание, ИИ-программа «МехИИ», поступление, методическая поддержка преподавателей, конкурсы и аналитика гибридного образования.

> Сайт-портал: [`index.html`](index.html) — приветственная страница со ссылками на все материалы репозитория.

## Разделы подробнее

### 📅 Расписание Лицея 2026–2027

Две версии одной сетки уроков:
- **`lfu_2026-2027_shedule.html`** — с кабинетами, полные аналитические вкладки
- **`shedule.html`** — без кабинетов, упрощённая публикация для родителей

Поддерживает режимы «Очные / Онлайн / Дистанты / Элективы / Внеурочка / Разговоры о важном», поиск по предмету, учителю и кабинету, выезжающую панель с деталями урока.

### 🤖 ИИ-программа «МехИИ»

**`MechAI.html`** — аналитика 6 курсов внеурочной деятельности (программирование, промпт-инжиниринг, вайбкодинг, проектный практикум, ИИ-грамотность, кружок 8–9): тепловая карта дублирования, SWOT, матрица рисков, технические требования, оценка затрат, кадровые сценарии, бенчмарк с «Летово», СУНЦ МГУ, ISTE AI4K12.

**`MechAI_KTP.html`** — календарно-тематический план 10–11 класса (технологический профиль), интегрированный со сквозным ИИ-треком на 68 учебных недель. 9 предметов: математика, информатика, английский, физика, русский, литература, история. Каждая неделя снабжена комментарием о межпредметных связях.

### 🎓 Поступление в Финуниверситет 2026

**`fa_priemka_2026.html`** — единый гид абитуриента: ключевые изменения (только Госуслуги, без оригиналов), таймлайн приёмной кампании, диаграмма Ганта, калькулятор шансов на бюджет, карта сайта `fa.ru`, процесс подачи в виде блок-схемы, квоты и платное обучение, FAQ-аккордеон.

### 🛠️ Преподавателю

**`online_lfu.html`** — тёмное руководство для преподавателя: как писать вопросы в Word по 11 типам (multichoice, shortanswer, numerical, matching, gapselect, cloze…), как пользоваться конвертером [`Moodle-WORD-to-XML-Converter-v3`](https://github.com/altersam/Moodle-WORD-to-XML-Converter-v3), создавать тесты и курсы в Moodle на `edu.fa.ru`, проводить вебинары в МТС Линк с группами, доской и расшифровкой, генерировать ИИ-конспекты.

### 🏆 Конкурс ВарФин 2026

**`VarFin_instructions_jury.html`** — интерактивная инструкция для члена жюри: живой пример карточки участника с тултипами, переключение между заявкой (PPTX) и тезисами (DOCX) через Office Online, скачивание материалов, форма оценивания в Bitrix24, таблица критериев (стиль / методология / выступление).

### 📊 Аналитика

**`distant.html`** — исследование распределённого и гибридного обучения в школах и вузах РФ: типовые профили (технологический, гуманитарный, экономический), статистика, модели, кейсы и практические рекомендации Лицеея Финуниверситета.

## Использование

Каждый файл — самодостаточный одностраничный HTML (`lang="ru"`, UTF-8): без сборки, без npm, без зависимостей (единственное исключение — `fa_priemka_2026.html` подключает Chart.js через CDN). Достаточно:

- открыть файл двойным кликом в браузере, или
- просмотреть на GitHub Pages (см. ниже).

### Запуск локально

```bash
git clone https://github.com/Altersam/LFU.git
cd LFU
start index.html   # Windows
# open index.html  # macOS
# xdg-open index.html   # Linux
```

Или поднять простой статический сервер:

```bash
python -m http.server 8000
# http://localhost:8000
```

### Публикация на GitHub Pages

1. Убедитесь, что все HTML-файлы лежат в корне репозитория на ветке `main`.
2. **Settings → Pages → Source → Deploy from branch → `main` / `(root)`**.
3. Через ~1 минуту сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/LFU/`

Индекс-портал `index.html` автоматически поднимется как главная страница.

## Технологии

- Чистый HTML5 / CSS3 (встраиваемые `<style>`, без внешних CSS-фреймворков)
- Нативный JavaScript (вкладки, фильтры, аккордеоны, калькуляторы)
- Chart.js (CDN) в `fa_priemka_2026.html`
- Адаптивная вёрстка с медиазапросами вплоть до 480px
- Цветовая палитра фирменного стиля Финуниверситета: тёмно-синий `#003478`, бирюзовый `#0b7285 / #1098ad`, золото `#f0b429`
