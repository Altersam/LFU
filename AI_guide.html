Сравнительная памятка: какие нейросети выбрать под конкретную педагогическую задачу, где работать — в браузере, программе на ПК или смартфоне, когда достаточно бесплатного тарифа и когда нужен локальный запуск. Названия сервисов кликабельны, а технические термины объясняются по нажатию.

Обычный режим — сервисы и готовые промпты. Продвинутый — модели, Hugging Face, локальный запуск и сервер.

1Сначала бесплатный вариант
Для нескольких задач в неделю подписка обычно не нужна: free-tier сейчас есть у DeepSeek, Kimi, Mistral Vibe, Perplexity, Gamma, ElevenLabs и многих других.
2Подписка — когда есть регулярная нагрузка
Платить имеет смысл за большие лимиты, приватность, коммерческие права, deep исследование, агентное программирование или постоянную генерацию медиа.
3Для закрытых документов — локально
Ollama / LM Studio / Jan / AnythingLLM позволяют оставить тексты и документы на своём ПК или школьном сервере.
Что в таблице значит «без VPN». Это практическая категория на дату сборки: сервис не относится к явно неподдерживаемым для РФ и обычно открывается из российских сетей. Это не гарантия конкретного провайдера связи. Если компания официально исключает РФ из supported regions, такой сервис находится в отдельном разделе ниже — даже если технически его иногда удаётся открыть.

1. Что на самом деле скрывается за словом LLM

LLM

Большая языковая модель предсказывает следующий токен. Из этого механизма получаются чат, суммаризация, код, извлечение информации и агентные сценарии.

Base vs Instruct

Base — исходная модель после предобучения. Instruct / Chat — модель, дополнительно настроенная следовать человеческим инструкциям. Для обычного помощника почти всегда выбирайте Instruct.

Dense vs MoE

Dense активирует все параметры. MoE содержит набор «экспертов», но на каждом токене активирует лишь часть.

Размер модели

7B, 14B, 32B, 70B — миллиарды параметров. Чем больше модель, тем выше требования к памяти и обычно выше потенциальное качество.

Контекст

Количество токенов, которые модель может учитывать одновременно. Большой контекст полезен для документов, но увеличивает расход памяти на KV-cache.

Reasoning-модель

Оптимизирована под многошаговое решение задач. Обычно медленнее, но полезна для математики, анализа и программирования.

VLM

Vision-Language Model — языковая модель, которая принимает текст и изображения: скриншоты, схемы, графики, документы.

Embedding

Не чат, а модель, превращающая текст в числовой вектор. Нужна для смыслового поиска по базе документов.

Reranker

После первичного поиска получает запрос и найденные фрагменты и пересортировывает их по реальной релевантности.

Ключевой вывод: серьёзный ассистент обычно состоит не из одной нейросети. LLM отвечает, embedding ищет, reranker улучшает поиск, Whisper распознаёт речь, а отдельная diffusion-модель рисует изображения.

4. Пять способов запустить модель с Hugging Face

A — Inference Providers: ничего не скачивать

Подходит, если нужно быстро проверить модель или встроить её в небольшой скрипт без своего GPU.

pip install -U huggingface_hub

from huggingface_hub import InferenceClient

client = InferenceClient(
    api_key="hf_...",
    provider="auto"
)

answer = client.chat.completions.create(
    model="Qwen/Qwen3-8B",
    messages=[{"role": "user", "content": "Объясни закон Ома для 8 класса"}]
)

print(answer.choices[0].message.content)

Нужно создать Hugging Face token с правом inference. Провайдер можно выбирать автоматически или явно.

B — LM Studio: самый простой локальный интерфейс
  1. Установите LM Studio.
  2. В поиске введите Qwen3 8B GGUF или gpt-oss 20b.
  3. Для 16 ГБ RAM начните с 4–8B; для 32 ГБ — 8–14B.
  4. Выберите 4-bit quantization.
  5. Скачайте модель → Load → Chat.
  6. При необходимости включите Local Server.
C — Ollama: локальная модель и сервер одной командой
ollama pull qwen3:8b
ollama run qwen3:8b

# gpt-oss-20b:
ollama pull gpt-oss:20b
ollama run gpt-oss:20b

Ollama удобно использовать как backend: поверх него ставятся Open WebUI, AnythingLLM, Cline, OpenCode и другие клиенты.

    "text-generation",

Простой путь

Инженерный путь

Embedding → vector DB → reranker → LLM. Компоненты можно тестировать и менять независимо.

Обязательно

Показывайте источники. Если релевантного фрагмента нет — ассистент должен сообщать, что информации недостаточно.

Почему embedding + reranker

Embedding быстро отбирает похожие по смыслу фрагменты. Reranker медленнее, но глубже сравнивает каждый кандидат с запросом и улучшает итоговый порядок. Для небольшой локальной базы можно начать с BGE-M3 + Qwen3-Reranker-0.6B.

7. Не путать системный промпт, RAG и дообучение

Системная инструкция

Меняет поведение и формат: «ты методист», требования к ответу, запреты.

RAG

Добавляет актуальные знания из документов без изменения весов модели. Для положений и инструкций почти всегда нужен именно RAG.

Fine-tuning / LoRA

Меняет веса или адаптеры. Нужен, когда требуется устойчиво научить стилю, формату или специфическому паттерну.

Когда LoRA оправдана

  • есть сотни/тысячи хороших пар «вход → идеальный выход»;
  • нужен строго стабильный формат;
  • поведение не удаётся получить промптом;
  • есть отдельные train/validation данные и метрики качества.
Не дообучайте модель на документах только ради «знания документов». Документы меняются — для этого лучше RAG.

Домашний ПК, 16–32 ГБ RAM
